## 品質與技術問題

透明背景存在，但部分邊緣有彩色細碎像素與安全留白不足。學院非零透明邊界為 [15,56,1243,1222]；兵營 [0,0,1254,1238]；要塞 [0,11,1254,1254]。正式素材需一致留白、乾淨邊緣、地面錨點和陰影處理。大部分可見像素 alpha 接近255，但仍需在明暗底色檢查合成品質。

四張選用 PNG 合計約11.57MiB，完整RGBA解碼約24MiB（不含瀏覽器其他配置），尚未壓縮成遊戲交付資產。未測量 FPS、記憶體峰值、GPU 或真實裝置效能。不得把概念檔直接當手機正式資產。

圖片未使用第三方遊戲參考素材；使用依內建工具適用條款。尚未做完整相似性、商標、獨占權及商用法律審查，不宣稱權利保證。

## 分層製作可行性

可行，但需要重新繪製／補繪被遮蔽表面，不能把去背單圖當作分層素材。建議地面基座、主體、屋頂塔樓、庭院景觀、特色地標、旗幟、效果、前景遮擋各自交付；全部使用同一畫布、地面錨點、投影與像素尺度。

學院星象儀及浮空水晶、兵營白旗與誓約之泉、要塞旗幟與劍紀念碑可作獨立地標層。需先以視角／尺度樣板與簡單結構圖校準，再以本輪概念約束材質與配色。未來五階段需建築體量及結構連續成長，不能只增加光效；本輪未製作其他階段。

## 展示檢查與重現

執行 review/capture.cjs，使用 Linux Chromium。1600px比較板、1440px桌機、390px與320px手機模擬均成功載入所有圖片；documentWidth等於viewport，無水平溢出，外部網路請求為0。展示只含本機圖片與CSS，沒有 Firebase、登入、同步、業務儲存或執行階段腳本。未執行 macOS、iPhone實機測試，未執行 Repository build/lint/tests（未修改程式）。

可在此目錄執行：python -m http.server 8765 --bind 127.0.0.1
然後開啟 http://127.0.0.1:8765/review/comparison.html 或 review/thumbnails.html。這不是 Vercel 部署。
