# Becoming artwork

`aetheria.svg` is original vector artwork created for this repository's Phase 2A. It depicts the academy, keep and barracks in a border territory. No third-party game artwork, external image URL, font, WebGL or animation is used. The SVG is served locally with the application and scales using its viewBox; the app provides alternative text and a dark appearance treatment in kingdom.css.

`lord-emblem.svg` is an original anonymous hood, book and rune emblem for the Lord Profile. It does not depict a particular gender, real person or Google account; it uses no external avatar service.
