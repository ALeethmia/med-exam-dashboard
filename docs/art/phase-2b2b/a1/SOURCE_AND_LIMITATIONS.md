# 素材來源與技術限制

全部概念建築與場景使用ChatGPT內建image_gen，沒有採用付費外部圖像API或第三方遊戲美術參考。既有生成檔先保存於`/workspace/generated_images/`，各工作目錄只複製原始檔。A1.1參考已核准簡化版進行編修；獨立Academy及Keep參考修正版比較圖另行生成，並不是像素裁切。

比較板和桌機／手機展示PNG由原有HTML/CSS靜態展示與Linux Chromium截圖產生，原圖以CSS縮放展示；Pillow只用於讀取尺寸、透明模式與完整性。本次封存沒有執行圖片編修、壓縮、產圖或瀏覽器測試。

來源鏈：早期場景風格 → 原始三棟獨立圖與共同場景 → 使用者要求簡化後的三棟比較圖 → 簡化共同場景 → A1.1兩項局部修正 → 兩張A1.1獨立檢視圖。可核對檔案、實際來源路徑、尺寸與SHA256見ASSET_MANIFEST.json。沒有生成種子或完整模型版本，不能聲稱完全可重現。

原始A1_SOURCE_MANIFEST僅描述當時選用四張複雜版圖片，不是目前核准版本清單；本目錄README與A1_ACCEPTANCE指定目前基準。歷史原紀錄內的工作路徑可用來追溯，但不是Repository相對連結；不要在其他裝置假定這些路徑存在。

本輪不是法律審查。不新增CC0、MIT或其他圖片授權聲明；使用依服務適用條款及權利人實際情況判定。尚未完成完整相似性、商標、獨占權及商用權利審查。

原始複雜版獨立PNG具RGBA通道，但留白、邊緣與實際去背品質不足以當正式素材。核准A1.1為RGB扁平圖，沒有分層、錨點或遮擋補繪；不得把不同版本透明度混為一談。完整未驗證項目列於A1_ACCEPTANCE。
